# Frontend Design — Anti-Generic UI Craft

Defines the aesthetic bar, layout patterns, and visual identity required to bring web applications into the top 0.001% tier (Linear, Stripe, Apple, Vercel design calibre).

## Anti-Generic Design Principles

1. **Ban Generic "AI-Slop"**:
   - Avoid flat unstyled cards with centered generic text.
   - Avoid basic blue `#3B82F6` and plain bootstrap-style alert boxes.
   - Avoid overwhelming horizontal scrolling tables with 12 unformatted columns.
   - Avoid lifeless monochromatic gray boxes without depth or lighting.

2. **Distinct Visual Identity for MiAyudaTICS**:
   - **Tone**: Sophisticated, authoritative, high-efficiency institutional tech support.
   - **Color Balance**: Deep institutional accents (SENA emerald / vibrant tech teal / deep navy), rich slate backgrounds, and crisp text contrast.
   - **Lighting & Glassmorphism**: Translucent headers, cards with subtle inner glow (`box-shadow: inset 0 1px 0 0 rgba(255, 255, 255, 0.05)`), and hair-thin borders.

3. **Operational Workspace Architecture**:
   - **Multi-Role Differentiation**:
     * **Líder TIC / Admin**: High-level telemetry, KPI trends, batch assignment, SLA health radar.
     * **Técnico**: Rapid-action workspace, keyboard shortcuts, priority queue, quick case resolution drawer.
     * **Funcionario**: Frictionless conversational ticket filing, clear timeline status, zero confusing jargon.
   - **Split Panes & Detail Drawers**: Keep master context visible while inspecting ticket details.
   - **Scannable Micro-Typography**: Badges, timestamps in relative time (`hace 5 min`), tags, and status dots.

4. **Component Polishing Checklist**:
   - [ ] Every button has hover, active, focus-visible, and disabled states.
   - [ ] Badges include an icon or indicator dot beside the text for dual cognitive encoding.
   - [ ] Tables are enhanced with row-click selection, status chips, quick actions, and pagination or virtualization.
   - [ ] Modals and Drawers have smooth enter/exit transitions and backdrop blur.
